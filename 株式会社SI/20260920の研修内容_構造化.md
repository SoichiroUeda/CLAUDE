## 3. 市場価値とEQ

### 3-1. 市場価値の構造

市場価値とは、需要と供給による相対評価。**専門性 × 実績 × 再現性** の掛け算で決まる。

- **専門性**:AIに代替されたり、異動に弱かったりするため、長期的には武器になりにくい。
- **実績**:あればあるほど良いが、差別化がしづらい(例:大学時代にロボットを作った人と国体に出場した人を単純比較することは難しい)。表面的な経験だけでは弱い。
- **再現性**:成功・失敗の因果を論理的に説明し、過去を未来に応用する力。新卒に求められるのは、成果の再現性を言語化すること ── すなわちポータブルスキルとスタンスを得ること。

インターンで伸ばしたいのは、**再現性とEQ**。AI時代において「あなただから」と選ばれる力であり、人間力の向上につながる。

### 3-2. 再現性

- 再現性は、理論と実践を繰り返すことで生み出される。
- 理論内部のサイクル・実践内部のサイクルは、環境や周囲の人にサポートしてもらえるが、**理論と実践を横断するサイクルは自分の主体性でしかない**。

### 3-3. EQ(心の知能指数)

- EQとは心の知能指数であり、次の4要素に分解できる:**自己認識・自己管理・社会的認識・対人関係管理**。
- EQは、自分と他人の感情の理解であり、最終的に行動変容を生み出す。
- 自己実現とは、環境を選べる力だけでなく、環境を作る力をも指す。これができる人は究極のGiverである。

> **PMVVガイドブックとの関連(第6章 AI時代とEQ)**
> - EQ(Emotional Intelligence Quotient)は心理学者ダニエル・ゴールマンが広めた概念で、**自己認識・自己管理・共感(他者理解)・関係構築**の4要素で説明される。研修メモの4分解(自己認識・自己管理・社会的認識・対人関係管理)とほぼ対応している。
> - IQは生まれつきの要素が大きいが、EQは経験と訓練で後天的に伸ばせる。人と本気で向き合った数、本音を取りに行った数、信頼を積んだ数の分だけEQは高くなる。
> - AI時代にEQの価値が上がる理由:①知的アウトプットがコモディティ化する、②最後の意思決定は人の感情が動かす、③採用の現場で「AIに代替されない人材か」が裏テーマとして見られ始めている。

### 3-4. 失敗の捉え方

- **潜在的失敗**:行動しないこと。
- **顕在的失敗**:具体的な改善につながる失敗。

> **PMVVガイドブックとの関連(第11章)**
> 「顕在的な失敗を賞賛する」というバリューは、ハーバード大学エイミー・エドモンドソンの研究(優秀なチームほどミスの報告数が多い＝隠さず表に出す文化がある)を根拠にしている。表に出た失敗だけが組織の学びになる。

### 3-5. 中長期思考

- 成果を出す人は、短期的に良さそうなものに飛びつかず、中長期で考える。

## 4. ポータブルスキルとスタンス

### 4-1. 選定した3つのポータブルスキル

研修内で「ポータブルスキル大全から3つ選んでみよう」というワークにより選定した項目。**選んだもの ─ 選んだ理由 ─ どうやって実行するか** の形式で整理。

| 選んだスキル | 選んだ理由 | 実行方法 |
|---|---|---|
| 即レス | できるようになりたいから | 「確認します」など一次返信をする |
| 信頼残高 | 大切だとよく聞くから | 小さなことを一つ一つ丁寧に |
| 完了主義 | できるようになりたいから | 60点で一度見せることを宣言する |

以下、それぞれに対応する**ポータブルスキル大全**の該当項目(第1類プロフェッショナル・スタンス)の要点を補足する。

#### ① 即レス・即着手・ボールを持たない(項目2・重要度★☆☆)

> 仕事はキャッチボールに似ており、自分が返事や作業を止めている間、相手は次に進めない。信頼は仕事の質より先に、速さから生まれる ── 「あの人に投げれば必ずすぐ動く」という評判が仕事を引き寄せる。
>
> **基本の型**
> 1. 5分以内に「一次返信」をする(完璧な回答でなくてよい)
> 2. 2分で終わることはその場でやる
> 3. すぐできないときは着手予定を宣言する

#### ② 信頼残高(小さな約束の積み重ね)(項目8・重要度★★☆)

> 信頼を銀行口座のようにとらえ、日々の小さな行動で意図的に「入金」していく考え方。入金は少額ずつしかできないが、出金(約束を破る・遅刻する等)は一発で大きい。心理学の**損失回避**(マイナスの出来事はプラスの出来事の約2倍強く記憶される)がこの非対称性の背景にある。
>
> **基本の型**
> 1. 小さな約束ほど、ちゃんと守る
> 2. 守れない約束は最初からしない
> 3. 誰も見ていないところの行動を揃える
> 4. 出金してしまったら、素直に認めて早く返す

#### ③ 完了主義(60点でまず出す)(項目12・重要度★★☆)

> 100点を1回で出そうとせず、60点でいったん完了させて見せ、フィードバックをもらいながら磨いていく働き方。**100点の基準を持っているのは自分ではなく相手**であるため、早く見せるほどズレが小さいうちに軌道修正できる。60点で出すのは手抜きではなくリスク管理である。
>
> **基本の型**
> 1. 受けるときに「まずたたき台を出します」と宣言する
> 2. 6割できたら一度見せる
> 3. 自分の締め切りを、本当の締め切りの2割前に置く
> 4. 磨くのは指摘された場所だけ

### 4-2. ポータブルスキルのプラトーとスタートダッシュ

- ポータブルスキルはテクニカルスキルより伸びづらいため、初期にテクニカルスキルへ走ろうとしてしまいがち。
- ポータブルスキルのプラトー(停滞期)を早く抜けるためには、**スタートダッシュ**が大切。

### 4-3. スタンス・ポータブルスキル・テクニカルスキルの三層構造

- **スタンスが土台**、**ポータブルスキルが中段**、**テクニカルスキルが頂点**。
- 下が崩れてはいけない。

> **ポータブルスキル大全との関連**
> 大全の全体構成(全8類・92スキル)において、第1類「プロフェッショナル・スタンス」は「すべての土台。信頼される働き方の基本」と明記されており、研修メモの三層構造と一致する。即レス・信頼残高・完了主義はいずれも第1類(スタンス層)に属する項目である。

## 5. マーケティングの説明

### 5-1. マーケティングの定義

- 辞書的には、財・サービスが売れる仕組みを作ること。

### 5-2. カスタマージャーニーとファネル

- カスタマージャーニー:**認知 → 興味 → 情報収集 → 検討 → 購買(→ 拡散)**。それぞれの段階をファネルと呼ぶ。
- SNSマーケティングとは、SNSを接続媒体・オムニチャネルにして顧客を購買行動につなげること。

### 5-3. Instagram対TikTok

| | Instagram | TikTok |
|---|---|---|
| 特性 | 能動的アプリ。ユーザーが検索する。コミュニケーションハブ機能がある | 受動的アプリ。ユーザーは受け身。トレンドを作れる |
| 強み | 顧客ナーチャリングに適する。アカウント運用が無料で中小企業に嬉しい | 認知の獲得に適する。滞在時間が長く、MAUが多いためオムニチャネルとして適切 |

### 5-4. LIVE配信とオムニチャネル化

- 従来、SNSに関連するカスタマージャーニーはファネルごとに媒体が異なっており、ファネルが変化する際にユーザーが離脱しやすかった。SNSは伸びても売上につながりにくい状態だった。
- そこで、一つの媒体で完結させるために「投稿 × LIVE配信」の掛け算に変化。
- 現在はTikTok上で投稿 → LIVE → TikTok Shop → UGCまで、すべてTikTok内で完結するようになった。

### 5-5. ULSSASと市場データ

- **ULSSAS**:UGC → LIKE → Search1 → Search2 → Action → Spread
- 2024年の日本のB2C ECにおけるライブコマース比率は2%(規模としては大きい)。
- LIVE配信はクリエイター市場の20%を占める。

### 5-6. LIVE配信アプリの競争

- LIVE配信アプリ各社は「第一想起」の獲得を目指して競争している。TikTokが最も躍進。
- TikTokユーザーの平均年齢は39.2歳(比較的富裕層)。
- TikTokは公式プロモーション・公式イベント・アワードでLIVEを後押し(サンリオ・桃鉄など有名IPとのタイアップ)。
- TikTokは受動的アプリであるため、投稿の閲覧だけではナーチャリングが課題だった。投稿は受動的だがLIVEは能動的であるため、一つのプラットフォーム内で育成(ナーチャリング)につなげられる。
- ファネル間の離脱が少なくなることで、検討ファネルの期間が短縮される。

### 5-7. インサイトとマーケティング思考力

- 現在、市場価値が高いのは「SNSとビジネスを掛け算できる人」。会社で地位のある人ほどSNSネイティブではない、という非対称性がある。
- **インサイト**とは、消費者自身も自覚していない行動の深層心理。
- マーケティングを学ぶとは、手法や戦略そのものではなく、顧客のインサイトを分析することであり、それから初めて手法を考える。
- 人間は不合理な選択をすることがあるため、インサイト分析には行動経済学が役立つ。
- **インサイト分析能力はEQに同じ**(→[3-3節](#3-3-eq心の知能指数)参照)。
- マーケティングとは、どんな市場でも人間が無意識・不合理な意思決定をすることを前提に、行動経済学をもとにインサイトを分析し、財・サービスが売れる仕組みを作ることである。
- **マーケティング思考力**の3要素:①様々な事柄に疑問を持つこと、②すべてを美点凝視すること、③自己認知能力。
  - 美点凝視:長所や優れている点を注視して相手に伝えること。自分が興味のないものほど美点凝視するとよい。
  - 自己認知能力:他人を理解するには、まず自分を理解する必要がある。

## 6. 投稿・LIVE配信の説明

### 6-1. コンセプト=提供価値

- コンセプトとは提供価値のこと。提供価値を言語化することが大切であり、エゴになってはいけない ── 発信したいものよりも需要があるものを優先する。
- 人間は不合理な選択でも、価値を感じられればやってしまう。TikTokアカウントのライバルは他のあらゆる娯楽であり、可処分時間の奪い合いである。
- 鍛えたいのは、①需要を正しくつかむインサイト分析力、②正しく価値(開知)を提供する力の2つ。

### 6-2. ステップ1:アセットの理解

- 自分のアセット(生まれ持った特性や市場での立ち位置)を理解する。
- 自分自身のインサイト分析は、他の視聴者のインサイト分析と重なる部分がある。

### 6-3. ステップ2:TTP(徹底的にパクる)とバズ分析

- ベンチマークにするアカウントを見つけ、完璧に再現する(TTP=徹底的にパクる)。これが完了して初めて、アレンジを加え始める。
- 特定ジャンルのアカウントを30個ほどフォローし、上位アカウントの共通点を見つける。
- **バズ分析**の観点:冒頭・テロップ・構成・画角・BGMなど。「誰に・どんな価値を・どのように提供しているか」に着目する。
- アーティストよりもデザイナーを目指す ── すべてにロジックを持つこと(Logic Pro)。エゴになってはいけない。

> **ポータブルスキル大全との関連(守破離)**
> PMVVガイドブック第13章「バリュー⑥ トレンドを生み出す」で説明される**守破離**(守:優れた型を徹底的に真似て体に入れる/破:型を土台に自分なりの工夫を加える/離:型を離れ新しい価値を生み出す)は、このステップ2の「TTP→アレンジ」の流れと同一の構造。「守」のゴールは真似する行為そのものではなく、「いつでも、何度でも、狙って再現できる状態」に到達することとされている。

### 6-4. 配信の目的

- 配信の目的は、ナーチャリングしてマネタイズにつなげること。
- 投げ銭とは、ファン化の度合いを示す指標である。

## 7. PMVVとの接続整理

研修内容全体は、PMVVガイドブックが示す一本の線 ── **Purpose(ワクワクの連鎖) → Mission(可能性のIncubate) → Vision(Japan as Only One) → Value(SI WAY 7つの行動)** ── の上に成り立っている。

### 7-1. PMVVの要点

| 項目 | 内容 |
|---|---|
| Purpose(存在意義) | ワクワクが連鎖する社会を実現する |
| Mission(使命) | 一人ひとりの可能性を、Incubateする |
| Vision(目指す未来) | 心を動かす力で、Japan as Only One を実現する |
| Value(行動指針) | SI WAY ── EQを最大化する7つの行動 |

### 7-2. SI WAY(7つのバリュー)一覧

1. いつも素直に。感謝を忘れず。
2. ダサいことをしない
3. 与えるものが、全てを制する
4. 最上志向を持ち、顕在的な失敗を賞賛する
5. 本気で人と向き合う
6. トレンドを生み出す
7. 期待値を超えるエンターテイナーであれ

### 7-3. 研修内容とバリューの対応表

| 研修メモの内容 | 対応するSI WAY |
|---|---|
| 茶番・もてなし・感謝(1-2節) | ①いつも素直に。感謝を忘れず。 |
| 即レス・信頼残高(4-1節) | ②ダサいことをしない |
| 感謝と称賛、失敗の記録の共有(3-4節) | ③与えるものが、全てを制する / ④最上志向を持ち、顕在的な失敗を賞賛する |
| 最上思考(1-3節) | ④最上志向を持ち、顕在的な失敗を賞賛する |
| インサイト分析・EQ(3-3, 5-7節) | ⑤本気で人と向き合う |
| TTP→アレンジ、守破離(6-3節) | ⑥トレンドを生み出す |
| コンセプト=提供価値、バズ分析(6-1, 6-3節) | ⑦期待値を超えるエンターテイナーであれ |
