## 0. 前提の確認

> **インサイトの定義(5-7節)**
> インサイトとは、消費者自身も自覚していない行動の深層心理。マーケティングを学ぶとは、手法や戦略そのものではなく、顧客のインサイトを分析することであり、それから初めて手法を考える。

> **コンセプト=提供価値(6-1節)**
> コンセプトとは提供価値のこと。提供価値を言語化することが大切であり、エゴになってはいけない ── 発信したいものよりも需要があるものを優先する。

> **バズ分析の観点(6-3節)**
> 冒頭・テロップ・構成・画角・BGMなど。「誰に・どんな価値を・どのように提供しているか」に着目する。

以下、この3つの定義に沿って、選定した3投稿(アカウント2つ)を分析する。

## 動画1:譲り上手なトラック(@yukky_tru)

### バズ分析

| 観点 | 内容 |
|---|---|
| 画角 | ドライブレコーダー視点で固定。動画開始から終了まで視点変化なし |
| BGM | なし |
| テロップ | 画面上部に固定タイトル表示、下部に機械音声の発話内容を逐語表示。1行ごとに頻繁に切り替わる。機械音声は常時発話するわけではなく、ドラレコの映像・音だけの"間"がある |
| コメント | 動画内容への共感・称賛、他の運転マナーが悪いドライバーへの嘆き、紹介された小技を実行するための質問が多い |
| ハッシュタグ | 運転マナー / 大型トラック / 長距離トラック運転手(ジャンル特化の3タグで固定) |
| 構成 | 冒頭からドラレコ映像に即座に機械音声の状況説明が始まる。トラック同士のライトカット・パッシング・ハザードによる譲り合いを実況し、最後に「トラックドライバー側の本音」で締める |

### 誰に・どんな価値を・どのように

- **誰に**:高速道路・長距離運転をする一般ドライバー。大型トラックに対して漠然とした威圧感・不信感を持っている層
- **どんな価値**:①プロ同士の合図のやり取り(ライトカット・パッシング・ハザード)という、教習所では教わらない現場の知識という実用的価値、②「トラック運転手も気を配っている」という業界イメージへのカウンターがもたらす安心・信頼という感情的価値
- **どのように**:ドラレコ視点+"間"のある機械音声解説で実況ドキュメンタリーとしてのリアリティを担保。BGMを排して情報の信憑性を強調。最後の一文で視聴者の前提を覆す構成

### インサイト

大型トラックのドライバーに対して「威圧的」「マナーが悪い」というイメージを無意識に抱いている視聴者は多い(コメント欄の"運転マナーが悪い人への嘆き"がこれを裏付ける)。この動画は、免許には載っていない現場のプロ同士の合図のやり取りを丁寧に解説することで、視聴者に「自分もこの"言語"を読み取れるようになりたい」という上達欲求を刺激すると同時に、「トラック運転手も自分と同じように気を配っている」という安心感を与えている。最後の「左車線と真ん中車線で完結できるならそうしたいと誰よりも思っているのは、他ならぬトラックドライバーです」という一文は、視聴者が無自覚に抱いていた「大型トラック=邪魔な存在」という前提そのものへの反論であり、この一文への納得・共感が保存率9.7%(3本中最高)に表れていると考えられる。

**簡潔に言うと**:大型トラックへの不信感を、プロ同士にしか見えていなかった"合図の言語"を見せることで覆し、安心感と上達欲求を同時に満たしている。

*私自身の視点*:運転の一つひとつの操作にこだわりを持ちたいと考えている人間として、この動画が扱っているのは単なる感動エピソードではなく、"合図の出し方・読み方"という具体的な運転技術そのものだと感じた。アクセル・ハンドル・ブレーキという物理操作の精度だけでなく、他車とのコミュニケーションという新しい上達軸があることに気づかされた点が、素直に刺さった理由だと思う。

## 動画2:【ジグザグ位置】車線変更オアシスポイントを作る(@yukky_tru)

### バズ分析

| 観点 | 内容 |
|---|---|
| 画角 | 動画1と同様、ドラレコ視点で固定 |
| BGM | なし |
| テロップ | 動画1と同一フォーマット(上段固定タイトル+下段逐語)。機械音声の"間"も同様に存在 |
| コメント | 動画1と概ね同じ傾向(共感・称賛・マナーへの嘆き・小技の質問)だが、コメント率は動画1より高い |
| ハッシュタグ | 動画1と完全に同一(運転マナー / 大型トラック / 長距離トラック運転手) |
| 構成 | 冒頭から即座に状況説明。単なる譲り合いではなく「なぜその位置に留まったか」「なぜ並ばずに前に出たか」という判断の理由を逐一解説し、最後に独自の造語「車線変更オアシスポイント」で概念化して締める |

### 誰に・どんな価値を・どのように

- **誰に**:動画1と同じく一般ドライバー。特に車線変更のタイミングに悩んだ経験がある層
- **どんな価値**:抽象的な「思いやり運転」ではなく、「ジグザグの位置関係を作る」という再現可能な技術として言語化された実用知識
- **どのように**:独自の名前(オアシスポイント)を与えることで、感覚的な行為を"型"として記憶・実践できる形に変換。動画1と同一フォーマットを使うことでアカウントとしての一貫性・信頼を維持しつつ、内容の新規性で差別化

### インサイト

車線変更をしたいのにできない、というストレスは多くのドライバーが日常的に感じているが、その解決策は「思いやりを持ちましょう」という抽象的なマナー論で語られがちで、具体的にどう行動すればいいかがわかりにくい。この動画は、その解決策を「ジグザグの位置関係を作る」「車線変更オアシスポイント」という独自の名前を持つ具体的な技術として提示している。名前がつくことで視聴者は「感覚ではなく型として実践できる」という有能感を得られ、これがコメント率5.8%(3本中最高)に表れていると考えられる。「なぜこの位置で待つのか」「なぜ並ばないのか」という判断そのものを言語化して見せることが、この動画の核心的な価値になっている。

**簡潔に言うと**:感覚頼りだった「思いやり運転」を、名前のついた再現可能な技術に変換することで、視聴者に実践できるという有能感を与えている。

*私自身の視点*:直感的に「なんとなく」やっていたかもしれない運転判断が、理屈と名前を与えられて体系化される感覚は、自分が運転のあらゆる操作に完璧を求めていることと重なる部分がある。「オアシスポイントを作る」という言葉は、次に運転するときに意識してしまうくらい記憶に残った。

## 動画3:京大女子の日常(@pika._.chu.01)

### バズ分析

| 観点 | 内容 |
|---|---|
| 画角 | 自宅内または京都大学構内での手持ち撮影。投稿者本人も一部映るが顔は隠している |
| BGM | あり(声はほぼなし)。SEを頻繁に使いリズムを作るタイプ |
| テロップ | フォント普通・アニメーションなし。白文字で、背景映像と色が近く読みにくい場面がある |
| コメント | 外見・料理・努力への称賛が多数。京大や特定学部への進路相談コメントも複数。パラソーシャルな親近感を示すコメント(以前の投稿の言及など)もあり |
| ハッシュタグ | 初投稿 / 京大女子 / 日常 / Vlog / 女子大生(属性・検索ワードを重視した5タグ) |
| 構成 | 冒頭3秒で5カットの高速モンタージュ(一部は本編映像の使い回し)からタイトルテロップ「京大女子授業ある日の1日Vlog」を提示。以降は朝〜就寝までの1日をVlog形式で追う。全21カット |

@yukky_tru と比べ、編集技術(テロップの視認性・アニメーション・BGMの有無)は作り込まれていない。それでも伸びている点は、後述のインサイトで扱う。

### 誰に・どんな価値を・どのように

- **誰に**:京大受験を検討している高校生・浪人生(特に女子)、あるいは「高学歴×可愛い」という組み合わせに憧れる層
- **どんな価値**:①京大生としての生活の疑似体験・ロールモデル提示(保存率の高さが裏付け)、②「勉強ができる子=地味」という偏見へのカウンターとなる共感、③進路決定の実利的な判断材料(学部・勉強法の相談コメントから)
- **どのように**:検索されやすい固有属性ワード(京大)をハッシュタグ・冒頭テロップで前面に出し検索流入を獲得。高速カットの冒頭で離脱を防ぎ、Vlog形式で日常の解像度を上げて疑似体験感を演出

### インサイト

「勉強ができる女性は地味・恋愛的魅力に欠ける」という偏見は、当人が自覚しないまま社会に根強く残っている。この動画は、家庭的な朝ごはん作り・身だしなみ・友人関係を匂わせる描写・資格勉強への真面目な取り組みを同じ人物の中に同時に見せることで、「知性」と「可愛らしさ・親しみやすさ」が両立するという実例を提示し、視聴者(特に進学を控えた女子高校生)に「自分もこうなれるかもしれない」という許可を無意識に与えている。コメント欄の「女に学は必要ない、ガリ勉はダサいみたいな風潮の時代じゃなくなってよかった」という発言は、このインサイトを視聴者自身がほぼそのまま言語化した直接的な証拠である。また京大受験や学部選びの相談コメントが複数見られることから、単なる憧れの消費ではなく「進路決定の判断材料」として実利的に消費されている側面もある。

**簡潔に言うと**:「勉強ができる女性は地味」という偏見に反する実例を見せることで、視聴者(特に受験生)に自己投影と許可を与えている。

*私自身の視点*:自分は京都大学の学生であり、このアカウントが扱う「京大」という属性そのものは共有している(女子学生向けという軸では想定視聴者の中心ではないが)。同じキャンパス・同じ学食のメニューや価格感を見ると、憧れというより"答え合わせ"に近い感覚で見てしまう。自分にとって当たり前の日常が、切り取られ編集されることで急に「見られる価値のあるもの」として立ち上がってくることへの新鮮さがある。これは動画1・2で運転操作という自分の当事者性の高い領域に惹かれたのと同じ構造で、「自分の身近な世界が、他人の目を通して再構成されたときに何が価値として抽出されるか」に興味を惹かれるのだと思う。
